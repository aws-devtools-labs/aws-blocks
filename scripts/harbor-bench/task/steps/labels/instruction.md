# Add labels

Add labels to each todo in `/app/todo-app`. Existing todos and their data must keep working.

- Each item has a text input labelled **Labels** (comma-separated) and shows each saved label in a `data-testid="todo-label"` element.
- **Save todo** saves labels with the title and due date. Trim whitespace, drop empty entries and remove duplicates. Clearing the input and saving removes all labels.
