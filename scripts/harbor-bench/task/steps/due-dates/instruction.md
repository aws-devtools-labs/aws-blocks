# Add due dates

Add an optional due date to each todo in `/app/todo-app`. Existing todos and their data must keep working and stay unchanged: test with todos you create, and delete only those.

- Each `data-testid="todo-item"` has a date input labelled **Due date**.
- **Save todo** saves the title and due date together. Clearing the date and saving removes it.
- Due dates survive a page reload and a server restart.
