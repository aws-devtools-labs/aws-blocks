# Security Policy

## Reporting a Vulnerability

If you discover a potential security issue in this project, we ask that you
notify AWS/Amazon Security via our
[vulnerability reporting page](https://aws.amazon.com/security/vulnerability-reporting/)
or directly via email to <aws-security@amazon.com>.

Please do **not** create a public GitHub issue, and please do **not** open a
pull request for the vulnerability. Reporting it privately helps us protect
users while a fix is prepared and released.

Please include as much of the following as you can:

- A description of the issue and the component or Building Block affected.
- Steps to reproduce, or a proof of concept.
- The version(s) affected (for example, the `@aws-blocks/*` package versions).
- Any potential impact you have identified.

## Supported Versions

Security fixes are released against the latest published version of the
`@aws-blocks/*` packages. We recommend staying on the most recent release to
receive security updates.
