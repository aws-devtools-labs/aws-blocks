## Known gaps in the native auth coverage (inputs to E3)

1. **OIDC is effectively untested locally.** The native OIDC e2e is gated by `RUN_OIDC=1`, which needs an HTTPS sandbox. The Dart OIDC suite doesn't run at all, and the two Swift OIDC tests return early and report "passed" in 0.000s. E3 should try running them against `bb-auth`'s local stub IdP, and make any test that can't run *skip visibly* rather than pass vacuously.
2. **Fixture `18-hybrid-arm` is never checked against the live block.** The fixtures regenerate from committed `spec.json` files, so a clean regen only proves the generators didn't change — not that the fixture matches the spec the auth block actually emits. E3 should add a check that regenerates the auth `spec.json` from the real block and compares it.
